• SHATY 🤖💜

Meu primeiro projeto na área de programação.

O SHATY começou como uma ideia simples: criar meu próprio assistente para desktop e, ao mesmo tempo, aprender programação construindo alguma coisa de verdade.

Hoje ele já consegue conversar com o Windows através de comandos e consultar algumas informações do PC.

• O que já tem

💿 Espaço do disco
🧠 Memória RAM
⚙️ Informações do sistema
🛡️ Windows Defender
🧹 Arquivos temporários
🌐 Conexões de rede
🛡️ Firewall
🦠 Ferramenta de remoção de malware do Windows
🩺 Diagnóstico geral
🧹 Limpeza de arquivos temporários com confirmação

• Comandos

Digite estes comandos diretamente no chat do SHATY:

| Comando              | O que faz                                                            |
| -------------------- | -------------------------------------------------------------------- |
| `ver espaço`         | Mostra o espaço livre no disco C:                                    |
| `ver memória`        | Mostra o uso da memória RAM                                          |
| `ver sistema`        | Mostra informações do Windows e do PC                                |
| `ver segurança`      | Verifica o status do Windows Defender                                |
| `ver limpeza`        | Mostra a quantidade e o tamanho dos arquivos temporários             |
| `limpar temporários` | Mostra os arquivos temporários e pede confirmação antes de limpar    |
| `fazer limpeza`      | Mesmo comando de limpeza                                             |
| `ver rede`           | Mostra a quantidade de conexões TCP ativas                           |
| `ver firewall`       | Mostra o status dos perfis do Firewall                               |
| `verificar vírus`    | Abre a Ferramenta de Remoção de Software Mal-Intencionado do Windows |
| `verificar malware`  | Mesmo comando acima                                                  |
| `diagnóstico`        | Executa várias verificações do PC de uma vez                         |

• Exemplo

Digite no chat:
"ver memória"


O SHATY consulta o Windows e pode responder:
🧠 RAM: 7.79 GB usados de 15.89 GB.

• Como foi feito

* JavaScript
* Electron
* Node.js
* HTML
* CSS
* PowerShell

O Electron é responsável pelo aplicativo desktop, enquanto o Node.js e o PowerShell permitem que o SHATY consulte recursos do Windows.
